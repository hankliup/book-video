## 2. 时间轴（实测切点）

### A. 0.00–1.50s 开口钩子

- 画面：一张「蜗牛爬在摊开的书上」的氛围图，缓慢推近。
- 字幕位置**不在下三分之一**，而在画面中部（中文字底 y≈345，英文在其下），这是全片唯一一次字幕上移——用位置变化标记"开场白"和"正文"的分界。
- 文案：`今天分享的是` / `Today's sharing is`。
- 语速：0.05s 就有人声，**没有片头留白**。

### B. 1.50–2.90s 书单闪切（全片最强的节奏装置）

- **12 张真实图书封面，每张精确 3 帧 = 0.125s，间隔零误差**（实测切点 1.55 / 1.68 / 1.80 / 1.93 / 2.05 / 2.17 / 2.30 / 2.42 / 2.51 / 2.63 / 2.76 / 2.88）。
- 换算：**每秒 8 次满幅内容替换**，纯硬切，零叠化。
- 识别出的封面：爱的艺术、向上生长、人生海海、我的阿勒泰、屏蔽力、被讨厌的勇气、当下的力量、百年孤独、杨绛传、乌合之众、自渡、父母的觉醒。
- 作用不是"介绍这些书"，而是两件事：① 用节拍器式的闪切制造生理性一顿；② 用 12 张真实封面给账号做"我读书"的信用背书。
- 这一段是**模板化**的——0.125s 的等间隔只可能来自时间线上的等距排布，不是手 K。

### C. 2.92–4.32s 揭示（本期主角登场）

- 画面：**《高手布局》实体书封面满幅**，占屏约 1.4s。
- 配音正好念书名（ASR：2.92–4.32「高手布局」）。
- 2.88→3.13 的差分从 0.125s 台阶变成 0.042s 三连，说明这里从硬切换成了叠化收尾。

### D. 4.3–5.2s 交接 + 常驻层入场（关键工艺）

叠化（约 0.5s）进行**的同时**，顶部三层信息**分三步错帧淡入**：

1. `《高手布局》`
2. `羽林/著`
3. `做事的永远干不过做局的`（书腰文案直接当常驻标签句）

同时左侧贴一张小封面缩略图，只存在于**第一个正文镜头**（约 4.5–8.5s），之后撤掉。
→ 即"封面满幅 → 封面缩小贴边 → 封面消失、只剩文字"三级退场，把"这是哪本书"这件事在 4 秒内交代干净，然后不再占用注意力。

### E. 5.3–44.6s 正文

- **18 条金句字幕 / 22 个语音段**，铺在 **8 个背景镜头**上，每镜 3.2–8.3s。
- 镜头之间全部是 **0.46–0.54s 叠化**（实测 11–13 帧 @24fps），无一处硬切。
- 结尾**没有片尾、没有 CTA、没有回封面**：最后一句「才能够百毒不侵」打完，画面亮度停在 54.6 直接截断（43.2–44.8s 实测均值 54.0→54.6，无淡出）。

## 4. 背景：静帧推近 + 少量真素材混用

对每个镜头取首尾两帧，用"居中缩放 + 平移"网格搜索去拟合，看模型能解释多少差异：

| 镜头 | 时间 | 模型解释度 | 判定 |
|---|---|---|---|
| 窗边侧脸 | 35.5→40.3 | 69%（scale 1.20，撞到搜索上界） | 静帧 + 强推近 |
| 颈部特写 | 21.0→23.0 | 79%（scale 1.02） | 静帧 + 推近 |
| 逆光剪影 | 12.8→14.8 | 82%（scale 1.05） | 静帧 + 推近 |
| 旗袍读书 | 17.0→19.0 | 72%（scale 1.07） | 静帧 + 推近 |
| 旗袍读书 | 6.0→8.0 | 22% | **真实动态素材**（翻页、手部在动） |
| 亮片心形 | 29.6→34.0 | 6% | **真实动态素材**（物体自身在转） |

推近速度约 **2–4%/秒**，一个镜头累计放大 10–20%。

调色：整幅均值在 **40.8 ~ 106.0** 之间（最暗与最亮镜头差 2.6 倍），说明**没有统一归一化**，靠"暗调 + 压角"的选图习惯凑出一致观感；顶部书名所在区域均值实测 49 / 65 / 65 / 58 / **143** / **145** / 108 —— 后三个镜头书名区是亮的。

## 5. 字幕系统（这套工艺的核心）

### 5.1 显现方式：逐字打字机

20fps 抓 t=20.20–21.40 的 24 帧序列可见：`微` → `微笑和沉` → `微笑和沉默是` → … → 完整句，最右一个字先半透明再变实。中文行和英文行**同向同时**显现，整段约 0.25–0.5s。

### 5.2 字幕与语音的对齐（逐条对照 whisper 时间轴）

| 语音段（ASR） | 字幕上屏（OCR） | 起幅滞后 |
|---|---|---|
| 当女性开始看谋略的书 5.32–7.36 | 5.62–7.38 | +0.30s |
| 就会知道 7.36–8.48 | 7.88–8.62 | +0.52s |
| 永远不要愤怒 12.12–14.04 | 12.62–13.62 | +0.50s |
| 愤怒只会降低你的智慧 14.04–16.48 | 14.62–16.12 | +0.58s |
| 微笑和沉默 20.28–21.56 + 是两个最有效的武器 21.56–23.68 | 合并为一条 20.62–23.38 | — |
| 所有的负面情绪 38.12–39.72 + 都源于你的弱小 39.72–41.40 | 合并为一条 38.62–41.12 | — |
| 才能够百毒不侵 43.00–44.60 | 43.38–44.38 | +0.38s |

规律：**起幅滞后语音 0.3–0.6s，收幅比下一句早 0.2–0.3s，句间留 0.5–1.0s 空窗**（实测空窗点 7.38→7.88、13.62→14.62、19.88→20.62、26.12→26.88、31.88→32.62、34.62→35.38、41.12→41.88、42.88→43.38）。
即：**字幕不铺满时间轴，一条一句、之间断气**；切分按语义短语走，不按语音停顿走，所以"字幕条数(18) ≠ 语音段数(22)"。

这是一种"读起来舒服但技术上不精确"的做法——滞后 0.3–0.6s 人眼不觉得错，但绝不等于逐词对齐。

### 5.3 双语句：英文是质感道具，不是翻译

OCR 抓到的英文原样：

- `The more you care about what?`（你越在意什么）
- `What will you be tortured by?` / 拼成过 `fortured`
- `None of them were wise.`（没有一个是智者）
- `Angry Decause you are not generous enough`（大小写混乱）
- `Silence avoids many problems`

机翻直译、大小写与标点不统一、有拼错。它的作用是把单行字幕撑成"两行电影字幕"的版式，**不承担阅读功能**。

### 5.4 一条硬约束：每句 ≤ 14 字，永不折行

14 字句实测宽 630px / 画布 720px = 87%，已经贴到边。全片最长就是 14 字（`所有的负面情绪都源于你的弱小`、`微笑和沉默是两个最有效的武器`）。
→ **折行不是被渲染器禁掉的，是被文案禁掉的**：写稿时就按 ≤14 字断句，所以永远一行。

## 6. 音频工艺

- **人声**：F0 实测 163 / 176 / 178 / 163 / 180 Hz（女声中高音区），五处取样方差极小，全程无换气声。
- **停顿**：`silencedetect -35dB d=0.25` 在整片 **0 条静音**；−20dB 下只找到 1.72–2.92 和 4.32–5.32 两个空档。语音均值 −14.1 dBFS，空档仍有 −20.1 / −26.0 dBFS → **底下有一层从头铺到尾、从不避让的音乐床**。
- **语速**：全片 158 字 / 42.4s 有效语音 ≈ **3.7 字/秒**（本仓库实测口径是 4.69 字/秒，即这条比本仓库慢约 21%，配合音乐制造"沉住气说金句"的节奏）。
- **响度**：−10.8 LUFS / +2.8 dBTP / LRA 2.2 LU。这是**过压到削顶**的成品：平台按 −14 LUFS 归一化会整体拉低，且 +2.8 dBTP 已是互采样削波。采样峰值 −0.03 dBFS、满刻度样本 0 个，说明是限制器（limiter）而非简单增益，动态被完全压平。

## 7. 文案引擎（编辑层面的真正配方）

把口播稿单独拎出来看结构：

```
今天分享的是  +  《高手布局》          ← 报菜名，不解释
当女性开始看谋略的书，就会知道        ← 身份代入（不是"你有没有想过"）
动不动就生气的人，没有一个是智者      ← 断言
永远不要愤怒，愤怒只会降低你的智慧    ← 断言 + 理由
真正的高手，说软话做狠事              ← 对仗
微笑和沉默是两个最有效的武器          ← 工具化
微笑能解决很多问题，沉默能够避免很多问题 ← 镜像对仗
生气是因为你不够大度，郁闷是因为你不够豁达 ← 归因于己
你越在意什么，就会被什么折磨          ← 金句
所有的负面情绪都源于你的弱小，
唯有强大自己，才能够百毒不侵          ← 收口，回到"你"
```

特征：

1. **全片零剧情、零人物、零作者介绍、零"这本书讲了什么"**——18 句全是可独立转发的金句。书只是素材来源和封面锚点。
2. **一句一个信息，句间无连接词**，所以任何一句被截出来当封面/标题都成立（利于切片和二次分发）。
3. **身份钩子**（"当女性开始看谋略的书"）而非疑问钩子，把"看这条视频"变成"确认我是这类人"。
4. **镜像对仗**是主要修辞（微笑/沉默、生气/郁闷、说软话/做狠事）。
5. **结尾不号召、不引导关注**，停在情绪上（"百毒不侵"）。

## 8. 可复现的制作管线

按测量结果反推，一条这样的视频最少需要这些步骤：

1. **选书 + 摘 18 句**：从书里/网摘里挑可独立成立的断言，**每句 ≤14 字**，写成 CSV（句序 = 时间轴）。
2. **译 18 句英文**：机翻即可，不做校对（英文只负责版式）。
3. **配音**：单一女声、慢速（≈3.7 字/秒）、无停顿感；一次性读完，不逐句录。
4. **建工程**：720×960 / 24fps 时间线。
5. **铺常驻层**（一次建好，全片不动）：书名 ≈104px、作者 ≈30px、标签句 ≈32px，宋体系白字 + 下投影，水平居中，顶部 y 54 / 189 / 241。
6. **排片头 4.5s**：氛围图（1.5s，字幕上移到画面中部）→ 12 张封面等距闪切（每张 3 帧，直接复制粘贴成等距块）→ 本期封面满幅 1.4s。
7. **铺正文背景**：8 个镜头（静帧 + 2–4%/s 推近，或短动态素材），每镜 3–8s，镜头间 0.5s 叠化。
8. **贴字幕**：中文 42–45px + 英文 26px，居中，y 723 / 793，加**打字机**入场动画（≈0.3–0.5s），每条按语音段手动摆位、起幅比语音晚 0.3–0.6s、句间留 0.5–1.0s 空窗。
9. **压模板水印条 + 账号名**：一条覆盖全片的 PNG/贴纸层。
10. **混音**：音乐床全程不避让，总线挂限制器推到 −10 LUFS 左右导出。

判断：这是一个**模板 + 剪映类工具**的产物（等距闪切块、打字机预设、电影感水印条、常驻文字层、叠化默认时长都是编辑器预设形态），不是逐帧合成工程。

| 字幕对齐 | 起幅滞后 0.3–0.6s，句间断气 | ASR token + 能量窗逐行覆盖，三道门禁 | 本仓库严格得多；它的做法在人工观感上"够用" |
| 语速 | 3.7 字/秒 | 4.69 字/秒 | 它慢 21%，靠音乐撑节奏 |
| 响度 | −10.8 LUFS / +2.8 dBTP | 平台规范 | 它过压削顶，是缺陷不是风格 |
| 常驻声明 | 电影感模板水印（含"xingtu"字样） | 「内容为书评与感悟 素材来源于网络」 | 它的水印是第三方模板自带，非合规声明 |

**值得借鉴的三点：**

1. **常驻第三层"标签句"**：把书腰金句钉在顶部常驻，等于让主题句在屏幕上停留整片，比只在开头念一次强得多。本仓库现在只有书名 + 作者。
2. **≤14 字、永不折行的文案纪律**：把排版约束前移到写稿阶段，屏幕上永远一行，阅读负担最低。本仓库允许 2 行，但可以在 `validate-script.mjs` 里加一条"单行可容纳"的建议性检查。
3. **句间断气**：字幕不铺满时间轴，句与句之间留 0.5–1.0s 纯画面。本仓库的 C/C2 规则在消灭"空放"，但反过来也可能消灭了这种呼吸感——值得对照交付片看是否留了空窗。

**不建议照搬的四点：**

1. **12 张封面 8 次/秒满幅闪切**：这正是本仓库 2026-10-04/05 用户连续报"片头闪屏"的那类装置，判据⑤（帧间像素 MAD）会红。要做也得放慢到 ≥0.3s/张并压小变化面积。
2. **响度 −10.8 LUFS / +2.8 dBTP**：平台会拉低并暴露削顶。
3. **未校对的机翻英文**：`fortured`、`The more you care about what?` 这类错误会削弱"电影感"想营造的高级感。
4. **常驻层在亮背景上失读**：t=31/37/43 书名区背景均值 108–145，结尾那轮"月亮"更亮，白字加弱投影直接糊掉。本仓库的常驻层有统一压暗逻辑，比它稳。
