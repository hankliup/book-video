# 素材来源底线

- Background stills come from Pexels real photography, not from AI image generation. Search with `orientation=portrait`, take the original-resolution source (`src.original`, never Pexels' 810px `portrait` preset), crop to 1024x1365 (3:4) so the 720x960 frame is always down-sampled, and grade the full set in one pass so cuts do not jump in brightness or colour. Pick by atmosphere, not by literal illustration: one photo per narrative beat, chosen for light, colour temperature and emptiness. AI bitmaps are a fallback only when no Pexels photo can carry a beat; label such an image explicitly in `prompts.csv` and keep the fallback to a minimum. Do not use SVG as the main visual.
- Do not use card UI, third-party or stock watermarks left in the frame, copied frames, book-cover mockups, or literal image prompts that weaken atmosphere.
