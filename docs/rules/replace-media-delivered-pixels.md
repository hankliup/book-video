The boundary sweep proves only "the frame shows what the caption track says at that moment" — it uses the track as its own truth, so an axis that drifts sixteen seconds still scores 156/156; the two axis gates that came before it compare *axis to axis*, so an axis whose rows are each a couple of seconds off its own sentence still passes them. Only the per-row coverage gate sees 《恶女的告白》 2026-09-28: 88 rows filling 227.6 s, six gates green, and 40 rows whose caption was not on screen while its words were spoken (|Δstart| median 3.04 s, max 11.82 s). The sweep has its own failure mode, the **near tie**: it scores every candidate caption by IoU and takes the argmax, so two rows that differ by one glyph — 「她握了七十二秒」 vs 「她哭了七十二秒」 — differ by a handful of pixels, and a 0.001 IoU gap turned that into a false red (《三体3·死神永生》 2026-10-03, 2 of 310 points, verified by cropping the actual frames). When the losing margin is under `NEAR_TIE`, `scripts/qc-caption-alignment.py` now votes on the *difference region* instead of on the ratio: it counts frame ink only inside the pixels where the two candidates disagree, overturns the argmax only when the expected row carries strictly more ink there, calls an exact tie clean, and prints the counter-evidence in the note when it still reports a mismatch.
