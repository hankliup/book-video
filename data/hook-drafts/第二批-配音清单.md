# 第二批钩子配音清单（10 期）

每段单独录一条，存成 `episodes/<书名>/钩子.mp3`（和第一批 10 期同样位置）。
每段两行，念完即止；块内第一行的《书名》是给你自己核对用的，不要念出来。
文案以 `episodes/<书名>/script-hook.csv` 为准（下面是从它抄出来的，不是另写一份）。

```
《三体2·黑暗森林》
越是不在乎的人，越容易被推上去。
我合上书，想起那件谁都不管、最后归了我的事。
```
→ 存到 `episodes/三体2·黑暗森林/钩子.mp3`　｜　封面钩子「那件谁都不管的事，最后归了谁」（14 字，刘慈欣 / 著）

```
《魔戒1·魔戒同盟》
没有人是准备好了才上路的。
我数了数，那句等准备好再做说了有几回。
```
→ 存到 `episodes/魔戒1·魔戒同盟/钩子.mp3`　｜　封面钩子「你还在等哪件事准备好」（10 字，J.R.R.托尔金 / 著）

```
《偏跟山过不去》
买齐装备的那一刻，最容易误以为已经出发。
我读完才承认，我买的装备比走过的路多。
```
→ 存到 `episodes/偏跟山过不去/钩子.mp3`　｜　封面钩子「家里那套只用过一次的装备」（12 字，比尔·布莱森 / 著）

```
《三体1·地球往事》
说对人类失望的人，往往是最还在意的那个。
那句算了我也说过，说完那天比想象中平静。
```
→ 存到 `episodes/三体1·地球往事/钩子.mp3`　｜　封面钩子「你说算了的时候在想什么」（11 字，刘慈欣 / 著）

```
《雨季不再来》
最难的那几年，没人告诉你它是有尽头的。
我把以为不会过去的那段日子，重新过了一遍。
```
→ 存到 `episodes/雨季不再来/钩子.mp3`　｜　封面钩子「那段你以为不会过去的日子」（12 字，三毛 / 著）

```
《夜晚的潜水艇》
想象力不是自己消失的，是人把它交出去的。
我合上书，想起我也交出去过一样东西。
```
→ 存到 `episodes/夜晚的潜水艇/钩子.mp3`　｜　封面钩子「你交出去的是哪一样」（9 字，陈春成 / 著）

```
《对我无害之人》
伤你最重的那个人，可能一次也没凶过你。
那几个再也没联系的人，我一次也没怪过谁。
```
→ 存到 `episodes/对我无害之人/钩子.mp3`　｜　封面钩子「那个一次也没凶过你的人」（11 字，崔恩荣 / 著）

```
《西线无战事》
把人送上前方的，往往是一句好听的话。
那句好听的话我照做过，做到哪一步我心里有数。
```
→ 存到 `episodes/西线无战事/钩子.mp3`　｜　封面钩子「那句好听的话送你去了哪」（11 字，埃里希·玛丽亚·雷马克 / 著）

```
《你也只活了一次》
你羡慕的那种活法，也要回去交房租。
那句等稳定下来再说，我说过很多次。
```
→ 存到 `episodes/你也只活了一次/钩子.mp3`　｜　封面钩子「你想换的那种活法贵不贵」（11 字，猴面包的树 / 著）

```
《穆斯林的葬礼》
越懂事的人，越容易被一套规矩埋掉。
家里那条没人敢问的规矩，我从小守到大。
```
→ 存到 `episodes/穆斯林的葬礼/钩子.mp3`　｜　封面钩子「你家那条没人敢问的规矩」（11 字，霍达 / 著）
