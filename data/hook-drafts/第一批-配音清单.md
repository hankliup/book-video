# 第一批钩子配音清单（10 期）

每段单独录一条，存成 `episodes/<书名>/钩子.mp3`（和德米安那 5 期同样位置）。
每段两行，念完即止；块内第一行的《书名》是给你自己核对用的，不要念出来。


```
《秋园》
把人逼到想死的，从来不只是穷。
我读完那天，把家里还在硬撑的那个人想了一遍。
```
→ 存到 `episodes/秋园/钩子.mp3`

```
《人间失格》
讨好是有账单的，只是它来得晚。
我读第一页就停了，因为它写的是我。
```
→ 存到 `episodes/人间失格/钩子.mp3`

```
《洛丽塔》
他管那种东西叫爱，叫了整本书。
我读到最后一行才想起，她一句也没说过。
```
→ 存到 `episodes/洛丽塔/钩子.mp3`

```
《魔戒3·王者归来》
打完那场仗的人，最难的一步是回家。
我合上书，想起自己那件做完也没轻松的事。
```
→ 存到 `episodes/魔戒3·王者归来/钩子.mp3`

```
《魔戒2·双塔殊途》
所谓靠得住，就是没人看着的时候你也还在做。
我读完那天，把今年一个人扛完的事数了一遍。
```
→ 存到 `episodes/魔戒2·双塔殊途/钩子.mp3`

```
《乱世佳人》
她把一个人爱了十二年，爱的是自己造的一张脸。
我合上书，把一直以为是的那个人重新想了一遍。
```
→ 存到 `episodes/乱世佳人/钩子.mp3`

```
《你的夏天还好吗》
成年人最贵的一句话，是我没事。
我读完那天，把最近一次说没事的那几天数了一遍。
```
→ 存到 `episodes/你的夏天还好吗/钩子.mp3`

```
《三体3·死神永生》
做个好人，和把事做对，是两回事。
我咽回去的那些话，在这本书里全有了下场。
```
→ 存到 `episodes/三体3·死神永生/钩子.mp3`

```
《酒吧长谈》
坏事的门槛，是一寸一寸习惯出来的。
我读完才承认，自己也在往下挪。
```
→ 存到 `episodes/酒吧长谈/钩子.mp3`

```
《麦田里的守望者》
看不惯这个世界，从来不是毛病。
我读完那天，把第一次看不惯的那件事重新想起来。
```
→ 存到 `episodes/麦田里的守望者/钩子.mp3`
